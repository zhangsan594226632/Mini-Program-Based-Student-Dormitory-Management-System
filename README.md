# Mini-Program-Based-Student-Dormitory-Management-System
【万字文档+源码】基于小程序疫情核酸预约系统-可用于毕设-课程设计-练手学习-学习资料分享-本项目开发了一个基于微信小程序的疫情核酸预约系统，包含小程序用户端和PC管理后台双端协同架构。系统针对传统线下核酸检测的管理痛点，实现了线上预约、医生审核、结果查询、防疫咨询等全流程数字化闭环。采用SpringBoot后端+微信小程序+Vue PC后台的技术栈，支持多角色权限管理、富文本编辑、图片上传等企业级功能。系统包含普通用户、医生、管理员三类角色，分别对应不同的操作权限和功能模块。通过线上线下结合的方案，有效降低了防疫工作压力，提高了管理效率，具有良好的实用性和推广价值。项目技术成熟可行，操作简
