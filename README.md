## 1 项目整体概述

### 1\.1 项目名称

基于小程序疫情核酸预约系统（疫情核酸预约小程序）

### 1\.2 项目开发背景

传统线下核酸检测模式存在诸多管理痛点：

1. 群众线下排队预约核酸，无线上预约渠道，现场人流聚集，登记信息依靠纸质表单，效率低下；

2. 核酸检测结果仅线下口头通知，群众无法线上实时查看本人检测报告；

3. 检测站点、检测项目信息不透明，群众无法快速查询就近采样点位；

4. 群众防疫疑问无线上咨询渠道，意见反馈、投诉留言无法数字化归档；

5. 医护人员、管理员缺少统一 PC 后台，预约信息、检测数据、公告资讯全靠手工 Excel 统计，审核、台账管理繁琐。

为实现核酸检测线上化、规范化管理，搭建**微信小程序用户前台 \+ Vue PC 医生 / 管理员后台**双端协同核酸预约系统，区分普通用户、医护医生、系统管理员三类角色，整合线上核酸预约、检测站点查询、检测结果查询、疫情公告、在线咨询、留言反馈、后台数据审核全业务闭环，降低线下防疫工作压力。

### 1\.3 项目开发目标与意义

#### 业务实用目标

1. 轻量化移动端入口：用户通过微信小程序无需下载 APP，完成核酸预约、站点查询、报告查看；

2. 三层角色权限隔离：普通用户、医护医生、系统管理员各司其职，操作权限分级管控；

3. 核酸全流程数字化：覆盖预约提交、医生审核、检测结果录入、报告查询完整业务链路；

4. PC 后台一站式管控：管理员维护用户、医生、检测站点、预约、公告、留言全量数据；医生仅处理核酸预约审核与检测结果录入；

5. 双向沟通渠道：小程序在线咨询、留言反馈，后台统一回复同步至小程序；

6. 标准化检索、分页、图文上传、富文本公告编辑，适配防疫办公台账归档需求。

#### 技术学习目标

实现「微信小程序 \+ SpringBoot 后端 \+ Vue PC 管理后台」三端联动架构，掌握小程序登录、图片上传、分页列表、跨端数据同步、多角色 Token 权限拦截、富文本编辑等企业级 Web 功能，可作为计算机专业毕业设计、社区 / 医院防疫数字化落地项目。

### 1\.4 项目核心亮点

1. **双端协同架构**：微信小程序面向群众轻量化使用，PC 后台面向医护、管理员集中数据管控，两端数据实时互通；

2. **三级精细化角色**：普通用户、医生、系统管理员独立账号体系，菜单、数据操作权限完全隔离；

3. **完整核酸业务闭环**：线上预约→医生审核→录入检测结果→用户线上查报告，全流程无纸化；

4. **防疫配套功能齐全**：检测站点查询、疫情公告图文推送、在线咨询、留言反馈，满足群众防疫咨询需求；

5. **多媒体内容支持**：小程序留言、后台公告、预约信息均支持图片上传，公告采用富文本编辑器排版；

6. **完善后台管理能力**：数据分页检索、单条 / 批量增删改查、状态审核、图文素材上传、轮播图管理一体化。

## 3 系统角色与权限划分

系统分为三类独立角色，操作权限完全隔离：

1. **普通用户（仅微信小程序）**

    - 注册账号登录小程序；

    - 浏览首页轮播、查看检测站点列表、阅读疫情公告；

    - 提交核酸预约单，查看本人预约审核状态；

    - 在线咨询、发布带图留言反馈，查看后台回复；

    - 个人中心查看预约信息、检测结果、修改账号密码；

    - 无后台数据编辑、删除、审核权限。

2. **医护医生（PC 后台）**

    - 医生账号登录 PC 后台；

    - 查看全部核酸预约列表，审核预约单（通过 / 未通过）；

    - 录入核酸检测编号、检测结果、采样时间，绑定用户信息；

    - 浏览用户留言，简单回复咨询内容；

    - 仅可操作预约、检测信息模块，无法管理用户、站点、公告等系统数据。

3. **系统管理员（PC 后台最高权限）**

    - 管理员账号登录 PC 后台；

    - 全模块数据管控：用户管理、医生管理、项目类型管理、检测站点管理、预约信息、检测信息、留言反馈；

    - 系统配置：轮播图上传、富文本疫情公告编辑发布、在线咨询内容管理；

    - 所有数据新增、详情查看、修改、删除、批量操作、关键词检索。

## 4 系统需求分析

### 4\.1 功能性需求

#### 微信小程序（普通用户端）

1. 登录注册：账号密码登录、注册新用户、忘记密码找回；

2. 首页模块：顶部轮播 Banner、快捷入口检测站点、疫情公告图文列表；

3. 检测站点模块：展示全部采样站点基础信息；

4. 疫情公告模块：浏览图文公告，点击查看完整详情；

5. 个人中心模块：

    - 检测站点、预约信息、检测信息、在线咨询、留言反馈五大功能入口；

    - 查看本人所有核酸预约记录、检测报告；

    - 发布文字 \+ 图片留言，查看管理员 / 医生回复；

6. 预约功能：选择站点、检测项目提交预约申请。

#### PC 医生 / 管理员后台

1. 后台首页：欢迎页面，展示系统标题；

2. 个人中心：修改登录密码、维护账号基础信息；

3. 用户管理：管理员维护全部小程序用户账号；

4. 医生管理：管理员新增、编辑、删除医护账号；

5. 项目类型管理：维护核酸检测项目分类；

6. 检测站点管理：新增采样站点、编辑站点信息；

7. 预约信息管理：

    - 分页展示全部预约单（预约编号、站点、用户、医生、审核状态）；

    - 详情查看、修改预约、删除预约、审核状态切换；

8. 检测信息管理：录入检测编号、采样图片、检测结果、采样时间，绑定用户与医生；

9. 留言反馈：查看用户提交留言，编辑回复内容提交；

10. 系统管理：轮播图上传、富文本疫情公告发布、在线咨询内容管理。

### 4\.2 非功能性需求

1. 性能需求：小程序页面加载≤1s，PC 后台接口响应≤1\.2s，单张上传图片限制 2MB 自动压缩，单表 1000 条数据流畅分页；

2. 安全需求：Token 登录拦截，未登录禁止访问功能页面；表单非空、手机号格式校验；角色越权访问拦截；

3. 易用性需求：小程序底部 Tab 一键切换页面；PC 后台统一侧边菜单栏，操作按钮标准化，弹窗提示操作成功 / 失败；

4. 兼容性需求：小程序兼容主流微信版本；PC 后台适配 1366×768 及以上分辨率电脑浏览器。

### 4\.3 可行性分析

1. 经济可行性：全部开发工具开源免费，微信小程序免费调试部署，可直接落地社区、医院防疫使用，替代纸质预约表单，减少线下人力成本；

2. 技术可行性：SpringBoot\+Vue \+ 微信小程序为成熟主流技术栈，预约审核、图片上传、富文本编辑、多角色权限均为标准 CRUD 业务功能，无高并发分布式复杂难点；

3. 操作可行性：小程序操作极简，普通群众仅需微信即可完成预约查报告；PC 后台布局清晰，医护、管理员具备基础电脑操作能力即可快速上手；

4. 业务可行性：贴合核酸采样预约、防疫资讯、群众咨询真实防疫业务场景，具备较强实际落地价值。

## 5 系统总体设计

### 5\.1 前后端分离整体三层架构

1. **前端展示层**：分为微信小程序用户端、PC 管理后台端，分别面向群众、医护 / 管理员，通过 HTTP 请求调用后端统一接口，不直接操作数据库；

2. **后端服务层（SpringBoot 四层分层）**

    - Controller 控制层：接收小程序、PC 后台请求，校验角色身份，调用业务层返回统一 JSON；

    - Service 业务层：实现预约审核、检测结果录入、留言回复、权限校验、跨端数据同步核心逻辑；

    - Mapper 持久层：MyBatis 执行多表关联增删改查 SQL；

    - Entity 实体层：映射数据库全部数据表字段；
    配套工具包：图片上传工具、Token 权限工具、分页工具；

3. **数据持久层（MySQL）**：存储用户、医生、预约、检测、站点、公告、留言、项目类型数据，事务保证预约审核、检测录入操作原子性。

### 5\.5 数据库总体 E\-R 模型设计

核心实体关联关系：

1. 用户 \(user\) 1 对多 预约单 \(appointment\)、留言 \(message\)、检测记录 \(test\_record\)：一名用户可多次预约核酸、多条留言、多条检测报告；

2. 医生 \(doctor\) 1 对多 预约单、检测记录：一名医护审核多条预约、录入多条检测结果；

3. 检测站点 \(site\) 1 对多 预约单：一个采样站点对应多条用户预约；

4. 项目类型 \(project\_type\) 1 对多 预约单：检测项目分类绑定预约记录；

5. 管理员发布多条公告 \(notice\)、轮播图素材。

### 5\.6 核心数据表结构说明

1. `user` 用户表：账号、密码、姓名、手机号、注册时间；

2. `doctor` 医生表：工号、姓名、密码、所属采样站点、权限标识；

3. `site` 检测站点表：站点名称、地址、采样时间、配图；

4. `project_type` 检测项目表：项目名称（核酸检测 / 混检等）；

5. `appointment` 预约表：预约编号、站点 ID、项目 ID、用户 ID、医生 ID、预约时间、审核状态、预约配图；

6. `test_record` 检测记录表：检测编号、预约 ID、用户 ID、医生 ID、采样图片、检测结果、采样日期；

7. `notice` 疫情公告表：标题、富文本正文、配图、发布时间；

8. `message` 留言反馈表：用户 ID、留言文字、留言图片、管理员回复、提交时间。

## 7 核心业务流程设计

### 7\.1 用户注册登录流程

1. 用户打开小程序登录页，点击「注册用户」填写账号密码完成注册；

2. 输入账号密码登录，后端校验通过生成 Token 存入小程序本地存储；

3. 未携带 Token 访问任意页面自动拦截跳转登录页；

4. 退出登录清空本地 Token，返回登录页面。

### 7\.2 核酸预约、医生审核流程

1. 用户小程序选择检测站点、检测项目，填写信息上传凭证图片提交预约；

2. PC 后台医生进入预约信息列表，查看新增预约单；

3. 医生审核，修改审核状态为「通过 / 未通过」并填写回复；

4. 用户小程序「预约信息」页面实时刷新查看审核结果。

### 7\.3 检测结果录入、用户查询流程

1. 医生审核通过预约后，进入检测信息管理，新建检测记录，录入检测编号、采样图、检测结果、采样日期；

2. 数据存入 test\_record 表，关联对应用户账号；

3. 用户小程序个人中心点击「检测信息」，加载本人全部核酸检测报告。

### 7\.4 留言反馈与后台回复流程

1. 用户小程序留言反馈模块，输入文字 \+ 上传图片提交留言；

2. PC 管理员 / 医生后台进入留言反馈页面，查看全部用户留言；

3. 编辑回复内容提交，更新留言表回复字段；

4. 用户重新打开留言页面，加载后台回复内容，完成线上咨询闭环。

## 9 项目部署运行完整步骤

### 9\.1 环境准备

1. 安装 JDK1\.8、MySQL8\.0、Node\.js v16 并配置环境变量；

2. 安装微信开发者工具用于小程序编译预览；

3. IDEA 导入后端项目，VS Code 分别打开小程序、PC 后台前端文件夹。

### 9\.2 数据库初始化

1. Navicat 新建数据库 `nucleic_acid_mini`，字符集 utf8mb4；

2. 执行项目 sql 文件夹完整建表脚本，生成用户、医生、预约、检测、站点、公告、留言数据表；

3. 预先插入测试用户、测试医生、管理员账号用于调试。

### 9\.3 SpringBoot 后端配置启动

1. 修改`application.yml`配置文件，填写本地 MySQL 账号密码、图片上传存储路径；

2. 配置后端服务端口（默认 8080）；

3. Maven 刷新全部依赖，运行`NucleicAcidApplication`启动后端服务，接口地址`http://localhost:8080`。

### 9\.4 PC 管理后台启动

1. VS Code 进入 nucleic\-acid\-admin 目录，终端执行`npm install`安装依赖；

2. 修改 api 全局请求地址指向本地后端接口；

3. `npm run serve`启动 PC 后台，浏览器访问后台地址登录医生 / 管理员账号。

### 9\.5 微信小程序运行调试

1. 微信开发者工具导入 nucleic\-acid\-mini 小程序项目；

2. 修改 utils 内请求地址为本地后端地址；

3. 点击编译预览，使用测试用户账号登录调试小程序全部功能。

## 10 项目总结



本系统采用「微信小程序用户端 \+ SpringBoot 后端 \+ Vue PC 医护 / 管理员后台」三端联动架构，面向核酸检测防疫场景，区分普通群众、医护医生、系统管理员三类角色，实现轻量化线上核酸预约、采样站点查询、检测报告线上查询、防疫公告推送、群众留言咨询，搭配 PC 后台一站式管控预约审核、检测录入、用户账号、采样站点、图文公告全量数据。系统实现多角色权限隔离、图文多媒体上传、富文本公告排版、跨端数据实时同步、分页检索、批量台账操作等核心功能，UI 简约轻量化，代码分层低耦合，数据表关联设计规范，既可以作为计算机专业毕业设计项目，也可直接落地社区、医院核酸采样数字化防疫管理使用。
